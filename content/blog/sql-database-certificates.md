데이터를 다루는 직무에서는 **SQL(구조화 질의어)** 활용 능력이 기본입니다. 개발자, 데이터 분석가, 기획자 모두 SQL을 알면 업무 폭이 넓어집니다. 관련 자격증은 민간 공인 자격이 중심이니 성격을 이해하고 선택하세요([국가·민간 자격](/blog/national-vs-private-certificates.html)).

## 대표 자격

- **SQLD(SQL 개발자)**: 데이터 모델링과 SQL 기본, 활용 능력을 평가하는 공인 민간자격입니다.
- **SQLP(SQL 전문가)**: 성능 튜닝 등 고급 능력을 평가하는 상위 자격입니다.
- **정보처리기사** 등 국가기술자격에도 데이터베이스 과목이 포함됩니다([IT 자격증 비교](/blog/it-certificate-comparison.html)).

## SQLD의 시험 범위

1. **데이터 모델링의 이해**: 개념, 논리, 물리 모델링과 정규화
2. **SQL 기본 및 활용**: SELECT, JOIN, 집계, 서브쿼리, 윈도우 함수 등

## 준비 방법

1. **개념 이해**: 데이터 모델링과 정규화를 그림으로 이해합니다.
2. **직접 실습**: 무료 DBMS에 데이터를 넣고 쿼리를 **직접 작성**합니다.
3. **기출문제 반복**: 출제 유형이 반복되는 경향이 있어 효과가 큽니다([기출 활용](/blog/past-exam-resources.html)).
4. 오답과 헷갈리는 문법은 **오답 카드**로 정리합니다([암기법](/blog/memorization-techniques.html)).
5. 일정은 [연간 계획](/blog/annual-exam-plan.html)에 맞춥니다.

## 데이터 분석과의 연결

- SQL은 [데이터 분석 자격증](/blog/data-analysis-certificates.html)을 준비하는 기초가 됩니다.
- 개발 직무에서는 백엔드 개발과 함께 쓰입니다.

## 학습 팁

- 자주 나오는 **JOIN과 GROUP BY 조합**을 여러 번 써 봅니다.
- 실행 결과를 예측하는 습관을 들이면 시험 문제를 빨리 풉니다.
- 시험 시간이 짧으니 **시간 배분 연습**이 필요합니다([시간 배분](/blog/exam-time-allocation.html)).

## 진로

- 백엔드 개발자, 데이터 분석가, BI 엔지니어, 데이터 기획
- 비전공자가 IT 직무로 전환할 때 **입문 증명**으로 활용하기 좋습니다([직무 전환](/blog/career-change-certificates.html)).
