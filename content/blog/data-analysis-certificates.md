데이터 분석은 직무 전환과 취업 준비에서 **관심이 높은 분야**지만, 자격증 종류가 많고 성격이 제각각이라 혼란스럽습니다. 목적에 맞게 어떤 자격이 적합한지 정리합니다. 시험 범위와 일정은 시행 기관 공고를 확인하세요.

## 대표 자격증

- **데이터분석 준전문가(ADsP)**: 데이터 이해, 분석 기획, 분석 기초를 평가하는 공인 민간자격
- **빅데이터분석기사**: 빅데이터 분석 전반을 다루는 국가기술자격
- **사회조사분석사**: 설문 설계와 통계 분석 중심의 국가기술자격([노무·상담 자격](/blog/labor-related-certificates.html)에서도 언급)
- **SQLD**: 데이터베이스 기초([SQL 자격증](/blog/sql-database-certificates.html))

## 난이도와 성격 비교

| 자격 | 성격 | 난이도 |
|---|---|---|
| ADsP | 개념과 기초 통계 중심, 입문용 | 낮음~중간 |
| SQLD | 데이터 모델링·SQL 활용 | 중간 |
| 사회조사분석사 | 통계와 조사 방법론 | 중간 |
| 빅데이터분석기사 | 이론과 실기(코딩), 종합 | 높음 |

## 선택 기준

1. **직무 목표**: 분석가, 기획자, 개발자 중 어느 쪽인지 정합니다.
2. **프로그래밍 경험**: 실기 코딩이 필요한 자격은 파이썬 기초가 필요합니다.
3. **준비 기간**: 입문 자격은 짧게, 종합 자격은 길게 잡습니다([연간 계획](/blog/annual-exam-plan.html)).
4. **채용 공고**에서 요구하는 자격을 확인합니다([직무 수요 분석](/blog/job-demand-analysis.html)).

## 준비 순서

1. **통계 기초**(평균, 분산, 확률, 가설 검정)를 익힙니다([계산 문제 대비](/blog/math-for-technical-exams.html)).
2. SQL과 파이썬 등 **도구 기초**를 학습합니다.
3. 자격 시험은 **기출 반복**으로 대비합니다([기출 활용](/blog/past-exam-resources.html)).
4. **작은 분석 프로젝트**(공공데이터 분석)를 만들어 포트폴리오로 씁니다.

## 자격증만으로는 부족

- 데이터 직무는 **실제 분석 경험과 포트폴리오**가 중요합니다.
- 공공데이터 포털의 데이터를 이용해 분석하고 결과를 글이나 대시보드로 정리하면 큰 도움이 됩니다.
- 자격은 **학습 방향과 기초 지식을 증명**하는 역할로 활용하세요([직무 전환](/blog/career-change-certificates.html)).

## 주의할 점

- 유행 분야는 **공인 정도가 다른 자격이 많으니** 성격을 확인하세요([국가·민간 자격](/blog/national-vs-private-certificates.html)).
- 광고성 강좌의 "취업 보장"을 조심하세요.

## 마무리

데이터 분석은 자격증, 도구, 프로젝트의 삼박자가 필요합니다. 입문 자격부터 차근차근 시작하세요.
