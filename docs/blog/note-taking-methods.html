오답 노트 만드는 법

  1. 틀린 문제의 번호와 출처를 적습니다.
  2. 틀린 이유를 한 줄로 씁니다(개념 부족, 계산 실수, 문제 오독).
  3. 올바른 개념을 내 말로 정리합니다.
  4. 일주일 뒤 다시 풀어 봅니다.

요약 노트 요령

  • 교재 분량의 10~20% 이하로 줄입니다.
  • 표와 키워드 중심으로 씁니다.
  • 자주 틀리는 수치와 용어는 별도 페이지에 모읍니다.

디지털 도구

플래시카드 앱을 쓰면 이동 중에도 복습할 수 있습니다(공부 앱).
