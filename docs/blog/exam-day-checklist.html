자격시험 전날·당일 체크리스트 — 준비물, 입실 시간, 컨디션 관리

2026-09-29 · gosapass 편집팀

오랫동안 준비한 시험을 준비물 누락이나 시간 착오로 놓치는 일은 생각보다 자주 발생합니다. 시험 전날과 당일에 확인할 사항을 체크리스트로 정리합니다.

시험 전날

  • [ ] 수험표를 출력하거나 저장했다(시험장 안내와 좌석 정보 확인)
  • [ ] 신분증을 준비했다(유효한 신분증인지 확인)
  • [ ] 시험장 위치와 이동 경로를 확인했다(대중교통, 소요 시간)
  • [ ] 입실 시간을 확인했다(늦으면 응시 불가)
  • [ ] 필기구, 계산기 등 허용된 준비물을 챙겼다
  • [ ] 실기라면 공구와 재료, 복장을 점검했다(실기 준비)
  • [ ] 알람을 두 개 이상 설정했다
  • [ ] 무리한 벼락치기보다 가벼운 복습과 충분한 수면을 선택했다

시험 당일 아침

  • [ ] 든든한 아침 식사와 수분 보충(과식과 카페인 과다는 피하기)
  • [ ] 여유 있게 출발해 입실 마감보다 30분 이상 일찍 도착
  • [ ] 휴대전화 전원과 규정에 맞는 보관
  • [ ] 화장실을 미리 다녀오기

시험장에서

  1. 좌석 확인: 수험번호와 좌석이 맞는지 확인합니다.
  2. 시험 안내 청취: 감독관의 주의사항을 끝까지 듣습니다.
  3. 답안 작성 규정 확인: 필기구, 답안 표기 방법(CBT는 화면 기능 안내)
  4. 시간 배분: 어려운 문제는 표시하고 넘어갑니다.
  5. 마지막 검토: 답안 표기 누락이 없는지 확인합니다.

실기 시험 추가 사항

  • 위생과 안전 규정 준수(조리, 용접 등)
  • 실수했을 때 당황하지 말고 수습 가능한 부분을 찾아 마무리
  • 작업 순서를 머릿속으로 미리 그려 보기

하지 말아야 할 것

  • 시험 직전까지 새로운 내용을 외우는 것
  • 부정행위로 오해받을 수 있는 행동(휴대전화 사용, 타인 답안 확인 등)
  • 시험 도중 옆 사람이나 시간에 신경 쓰는 것

마무리

시험 당일에는 실력이 아니라 준비와 침착함이 결과를 좌우합니다. 체크리스트로 실수를 막고 컨디션을 관리하세요. 접수 절차는 시험 접수부터 합격까지에서 확인할 수 있습니다.
